# SCP: Secret Laboratory — 3D

Фанатский 3D-прототип по мотивам SCP: Secret Laboratory. Godot 4, GDScript.

## Запуск

Откройте папку и запустите `ИГРАТЬ.bat`. Если Godot не установлен — скачайте с [godotengine.org](https://godotengine.org/download).

Управление: **WASD** — движение · **Shift** — бег · **F** — фонарь · **Esc** — пауза · **Enter** — начать · **R** — заново

## Что в игре

- 7 зон: Зона содержания, Офисы, Лаборатория, КПП/Гараж, Столовая, Реактор, Шлюз
- Три карты доступа (уровни 1–3), цветные двери
- **SCP-173**: замирает при взгляде, атакует при моргании
- **SCP-096 «Скромник»**: спит в Реакторе; взгляд >2 сек → бежит за тобой; контакт < 1.4 м = смерть; отвести взгляд на 3 сек = возвращается
- Фонарь с батареей, спринт с выносливостью, туман, предупреждение опасности
- Процедурный звук: шаги, сирена, сердцебиение, двери, крик 096

Весь код — один файл `scripts/level_builder.gd` (~1000 строк).
Прототип, не связан с Northwood Studios.
